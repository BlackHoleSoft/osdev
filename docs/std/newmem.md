# Модуль newmem - Управление динамической памятью в куче

## Обзор

Модуль `newmem` предоставляет реализацию динамического выделения памяти в куче для операционной системы Strelka. Он реализует стандартные функции C для управления памятью: `malloc`, `calloc`, `realloc` и `free`.

## Архитектура

### Структуры данных

#### `MemBlockHeader`
Структура, описывающая заголовок блока памяти:
- `size`: размер данных в блоке
- `is_free`: флаг, указывающий, свободен ли блок
- `next`: указатель на следующий блок в списке

#### `HeapInfo`
Статическая структура, хранящая информацию о куче:
- `start_addr`: начальный адрес области кучи
- `size`: общий размер кучи
- `first_block`: указатель на первый блок в куче

## API

### Функции выделения памяти

#### `malloc(size_t size)`
Выделяет блок памяти заданного размера и возвращает указатель на него.
- Возвращает `NULL`, если выделение невозможно
- Выравнивает размер до 8 байт для лучшей производительности
- Возвращает указатель на блок данных (без заголовка)

#### `calloc(size_t num, size_t size)`
Выделяет и инициализирует нулями память для `num` элементов размером `size` каждый.
- Возвращает `NULL`, если выделение невозможно
- Использует `malloc` для выделения памяти, затем заполняет её нулями с помощью `memset`

#### `realloc(void* ptr, size_t size)`
Изменяет размер выделенного блока памяти.
- Если `ptr` равен `NULL`, работает как `malloc(size)`
- Если `size` равен 0, освобождает блок и возвращает `NULL`
- Если новый размер меньше или равен текущему, может уменьшить блок
- Если новый размер больше, выделяет новый блок, копирует данные и освобождает старый

#### `free(void* ptr)`
Освобождает выделенный блок памяти.
- Проверяет, что указатель находится в пределах кучи
- Проверяет, что блок действительно выделен
- Объединяет освобожденный блок соседними свободными блоками

### Вспомогательные функции

#### `newmem_init(void* start_addr, size_t size)`
Инициализирует кучу по заданному адресу и размеру.
- Проверяет корректность параметров
- Создает первый блок памяти

#### `get_heap_used()`
Возвращает количество используемой памяти в куче.

#### `get_heap_free()`
Возвращает количество свободной памяти в куче.

## Алгоритмы

### Выделение памяти
- Используется алгоритм first-fit: ищет первый подходящий свободный блок
- При необходимости разделяет блок на два: занятый и свободный
- Выравнивание размера до 8 байт для оптимизации

### Освобождение памяти
- Помечает блок как свободный
- Объединяет с соседними свободными блоками для предотвращения фрагментации
- Проверяет корректность указателя перед освобождением

### Разделение блоков
- Происходит при выделении памяти, если найденный блок больше необходимого
- Создает новый заголовок для оставшейся части блока

### Объединение блоков
- Происходит при освобождении блока
- Объединяет с соседними свободными блоками для создания более крупных блоков

## Безопасность

- Проверка корректности указателей перед освобождением
- Проверка, что указатель принадлежит куче
- Проверка, что блок действительно выделен перед освобождением
- Защита от двойного освобождения

## Особенности реализации

- Использует односвязный список для отслеживания блоков памяти
- Выравнивание размеров для лучшей производительности
- Минимизация фрагментации за счёт объединения блоков
- Поддержка минимального размера блока для предотвращения ошибок
